# TestimonialHub

TestimonialHub is a testimonial collection and management platform built with Next.js. It helps users collect customer feedback, manage testimonials, and display them through public testimonial walls.

## Features

- User authentication and sign-up
- Workspace management
- Public testimonial collection forms
- Testimonial inbox and management
- Public Wall of Love pages
- Embeddable testimonial pages
- Input validation and submission rate limiting

## Technology Stack

- Next.js
- React
- TypeScript
- Prisma ORM
- PostgreSQL
- Auth.js
- Tailwind CSS
- Vitest
